一根管道：收进来 · 归好类 · 带得走

Glean 不是一个剪藏夹——它是你的收藏入口，把散落的内容变成井然有序、随时可带走的资产。

📥

收藏管道

不管内容从哪来，都进同一条管道：收件箱 → 归类 → 归档。

  • 手录收藏：备注 + 标签 + 分组
  • 剪贴板监听轻提示「有内容要收藏？」
  • 网页摘录自动带出处（原文链接 + 来源页标题）
  • 内容语言自动标注（中 / 日 / 英 / 其他）
🗂️

整理体系

待归类 → 已收藏 → 已归档，三层分类（库 → 子集）多对多归属。

  • 状态分段：待归类 / 已收藏 / 已归档 / 全部
  • 库 → 子集两级分组，主库标记默认归属
  • 多标签交叉，搜索增强
  • 桌面宽屏侧栏直达分组
🖼️

本地素材库

链接本地目录（不导入媒体），递归索引图片 / 视频，仅本地使用。

  • 文件夹链接 + 用途批注（这张图是干嘛用的）
  • 目录分组视图，网格 / 列表切换
  • 视频就地播放，素材随时引用进收藏
  • 素材不参与云同步——大文件只留在本机
☁️

数据带你走

同步只走你自己的云盘，导出随时带走，服务器零存储。

  • WebDAV 通道：启动静默合并 + 前台周期同步
  • 本机写入方（浏览器插件等）实时通知同步
  • 删除墓碑防复活，删除跨端生效
  • 一键导出 zip（JSON 机器可读），数据随时插拔

数据默认属于你

Glean 把「拿不回数据」的担心当作首要设计约束：本地优先，隐私默认。

同步走进你自己的云盘（WebDAV），服务器永不存储你的任何数据与媒体文件——这是架构上的铁律，不是口头承诺。

📦 收藏与素材数据默认仅保存在本机
📤 一键导出 zip，随时插拔
🔄 云盘同步：数据只进你自己的 WebDAV
🧹 可编辑、可删除、删了就是删了（删除跨端同步）
