收藏进得来、存得稳、带得走

从浏览器右键到你的私人云盘，一条管道全部打通。

🧲

六类收藏（浏览器扩展）

右键即收，任何抓不到的内容自动降级为引用，收藏动作永不失败。

  • 划词（文本 + 选区 HTML 快照）
  • 图片 / 视频·音频 / PDF 等任意文件直传媒体库
  • 网页链接 + 描述 / og 封面；批量收藏页面图片
  • 整页离线归档（静态资源内联为单文件 HTML）
🗂️

自动整理

收下的内容进收件箱，语言自动标注，随时归入你的分类。

  • 分类 / 子集两级体系 + 标签交叉
  • 中文 / 日语 / 英语等语言自动识别
  • 全文搜索：内容、出处、标签
  • 超体积弹窗询问「源文件 / 仅链接」
☁️

七种云盘通道

原生适配你已有的网盘，媒体文件也能从 App 打开。

  • iCloud / WebDAV（坚果云、NAS、alist）
  • 百度 / 阿里 / OneDrive / Dropbox / Google Drive
  • 启动合并 + 周期同步 + 插件写入实时通知
  • 打开媒体 / 离线页；一键清理云盘孤儿文件
🔒

数据属于你

本地优先 + 服务器零存储，是架构铁律不是口号。

  • 全部数据本地 SQLite，一键导出 zip（JSON 机器可读）
  • 云盘只进你自己的账号；媒体永不进第三方服务器
  • 删除跨端同步（墓碑防复活）
  • Apache-2.0 开源，可审计

云盘支持矩阵

数据只进你自己的账号；无 WebDAV 的网盘请用 alist 桥接（文档含 3 分钟配置）。

通道方式特点
iCloud Drive原生通道iOS 主力，ChatGPT 配额随用户
WebDAV标准协议坚果云 / 群晖·威联通 NAS / alist 桥接任意网盘
百度网盘原生适配器superfile2 分片上传，应用目录
阿里云盘原生适配器Open API 单分片直传
OneDrive原生适配器AppFolder 专用目录（不动用户文件）
Dropbox原生适配器App folder 权限，files/upload
Google Drive原生适配器AppData 专属空间（不触碰用户文件）

数据默认属于你

Glean 把「拿不回数据」的担心当作首要设计约束：本地优先，隐私默认。

同步走进你自己的云盘，服务器永不存储你的任何数据与媒体文件——这是架构上的铁律，不是口头承诺。

📦 收藏与媒体数据默认仅保存在本机
📤 一键导出 zip，随时插拔
🔄 云盘同步：只进你自己的账号（7 通道）
🧹 可编辑、可删除、删了就是删了（跨端同步）
