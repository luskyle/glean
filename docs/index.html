拾忆不是一个剪藏夹——收藏只是开始，复习负责记住，曲线负责证明。

📥

收藏管道

零等待入库：从任何位置把内容划进收件箱，App 自动成卡并安排首次复习。

  • 手录收藏：词条 / 语录 / 灵感
  • 剪贴板监听：复制即提示
  • 自动补释义、读音（离线词库优先）
  • 标签与分组：一条内容一个决定
🧠

间隔重复引擎

自研 SM-2 调度（纯函数、20+ 单测）：在对的时间复习，记忆效率最大化。

  • 闪卡先猜后看 + 三键评级
  • 忘了 / 模糊 / 记得 → 自动调整间隔
  • 断点续复习，随时退出不丢进度
  • review_log 全量留痕，可切 FSRS
📈

真实数据证明

成长感来自真实复习记录，无法假装学会——曲线会说实话。

  • 遗忘曲线：个人正确率 vs 理论目标
  • 掌握率、复习量、积压统计
  • 状态从日志派生（投影原则）
  • 一键导出 JSON，数据随时带走

数据默认属于你

拾忆把「拿不回数据」的担心当作首要设计约束：本地优先，隐私默认。

服务器永不存储你的任何媒体文件——这是架构上的铁律，不是口头承诺。

📦 收藏与复习数据默认仅保存在本机
📤 一键导出 JSON，随时插拔
🧹 可编辑、可删除、删了就是删了
🔐 剪藏只存引用与摘要，不托管原文
