# 记忆宫殿 App 架构设计

> 一款以「建造自己的记忆宫殿」为核心玩法的日语 / 英语学习 App。
> 依据《强化记忆方法详解》的方法论，把间隔重复、主动回忆、记忆宫殿、交错练习、多模态、情绪激励等科学方法**逐一翻译成游戏机制**，让用户"玩着玩着就记住了"。

## 一、设计总纲

### 1.1 一句话定位

> **把语言学习变成"建造记忆宫殿"：每一个记住的词都是一个家具，每一次复习都是给家具除尘养护，宫殿随词汇量越建越华丽。**

### 1.2 好玩有趣的三条铁律

| 铁律 | 含义 | 落地方式 |
| --- | --- | --- |
| 意义感 | 学习有看得见的终极目标 | 宫殿会成长：从茅屋 → 庄园 → 城堡 → 浮空城，用户亲手建造 |
| 即时正反馈 | 每个小动作都有回应 | 学一个词立刻拿到家具；复习一次立刻看到光泽回升；连击点燃宫殿烛火 |
| 低挫败 | 失败了也体面，不惩罚 | 遗忘只是"家具蒙尘"而非"失败"；答错不扣等级、不掉资源，只降光泽 |

### 1.3 方法论 → 玩法映射总表（核心设计依据）

| 调研文档的方法 | 游戏化翻译 | 让用户感受到的趣味 |
| --- | --- | --- |
| 间隔重复 SRS | **养护系统**：家具光泽按遗忘曲线衰减，蒙尘了要除尘 | 家具会"变脏"的成长模拟，养宠物的感觉 |
| 主动回忆 | **除尘先猜后看**：答题时背面先隐藏，揭开才见答案 | 开宝箱 / 猜卡面的惊喜感 |
| 记忆宫殿 | **宫殿系统**：每个房间 = 一个学习模块，家具 = 词卡 | 收集 + 布置 + 装修的核心乐趣 |
| 交错练习 | **远征混合任务**：一次远征混合新词、旧词、语法 | 路线随机，每次路线不一样 |
| 生成效应 | **家具工坊 DIY**：自己造句 / 录音 / 画卡面 | 亲手做的东西进宫殿，独一无二 |
| 精细加工 | **家具图鉴**：词根、例句、反义词做成家具的"故事" | 图鉴收集、点亮故事线 |
| 多模态 | **家具材质**：同一词有木雕（图）/ 铃音（音）/ 书页（例句）三种形态 | 集齐三件套点亮"套装效果" |
| 睡眠节律 | **安眠模式**：睡前复习包结束后宫殿入夜打烊，晨间开馆 | 跨天的"开门仪式感" |
| 情绪激励 | **连击 + 成就 + 宫殿展览会** | 徽章收集、好友参观点赞 |
| 数据与个性化 | **记忆年鉴**：个人遗忘曲线可视化，薄弱点做成"需要修缮的房间" | 看着自己宫殿的成长年鉴 |

## 二、世界观与核心玩法

### 2.1 世界观设定

你是一位**记忆建筑师**。进入一座名为「语之原」的大陆，大陆按学习内容划分为领地：

| 领地（房间） | 对应模块 | 例 |
| --- | --- | --- |
| 五十音庭院 | 假名 | あ 的樱花树、カ 的路灯 |
| 词汇客厅 | 单词 | 沙发的软垫上印着单词 |
| 汉字书房 | 汉字 | 每本书=一个汉字，书脊写音读 |
| 语法工坊 | 语法点 | 齿轮传动代表动词活用规则 |
| 听力花园 | 听力素材 | 喷泉会说话（播放音频） |
| 会话咖啡馆 | 句子与对话 | 每杯咖啡=一个常用表达 |

**核心对象：记忆家具（记忆藏品）**

- 每个已学习的词/语法点 = 一件家具，有卡面（正反向题面）和稀有度。
- 家具越用（复习）越光亮；长期不养护会蒙尘（光泽衰减 = 遗忘曲线可视化）。
- 家具分三种材质：**木雕（释义/图）、铃音（发音）、书页（例句）** —— 集齐同词三件套触发「套装共鸣」，宫殿获得特效。

### 2.2 核心循环（Core Loop）

```
  ┌─────────────── 探索（今日远征）───────────────┐
  │  领 3~5 个新词 = 在领地采集 3~5 个记忆种子        │
  └───────────────┬──────────────────────────────┘
                  ▼
  收集：种子变成「未布置家具」，放进仓库（图鉴点亮）
                  ▼
  布置：把家具放进对应房间 —— 放置前先主动回忆
        （"这个家具是什么？" → 猜对才摆正，猜错翻面）
                  ▼
  养护：家具光泽随时间衰减 → 每日「除尘」＝ SRS 复习
        （先猜后看 · 交错混合 · 摸到的家具会发光）
                  ▼
  成长：光泽拉满/连击断 → 家具升星、房间升级、宫殿进化
        （茅屋→庄园→城堡→浮空城）
                  ▼
  再探索（新词额度由昨天的养护表现决定，良性循环）
```

### 2.3 每日节奏（对应记忆节律）

| 时段 | 自动化安排 | 玩法名 | 科学依据 |
| --- | --- | --- | --- |
| 晨间（5 分钟） | 昨学内容快速回忆 | **晨间开馆**：开门时所有昨夜新家具露脸 | 次日晨间首复效率最高 |
| 白天（自定义） | 新词远征 + 常规养护 | **今日远征 / 除尘** | 间隔重复 |
| 睡前（10 分钟） | 今日新词巩固包 | **安眠模式**：宫殿入夜，烛火按连击点亮，第一句祝福语=今日巩固句 | 睡眠巩固 |

## 三、游戏系统设计

### 3.1 宫殿系统（核心场景）

- **2D 俯视 / 伪 3D 房间**：自由摆放家具，拖动、旋转、铺地毯、换墙纸（墙纸=主题皮肤：樱花季/圣诞/开学）。
- **房间解锁**：模块通关进度驱动，如五十音庭院全部家具拜访过 → 解锁书房。
- **宫殿等级**：由"宫内总光泽"决定，对应建筑外观进化（茅屋 → 木屋 → 庄园 → 城堡 → 浮空城）。
- **收藏柜**：家具图鉴，按稀有度与套装展示，未点亮的位置是"剪影+问号"，勾起收集欲。

### 3.2 养护系统（= 复习系统，SRS 可视化）

- 每件家具带**光泽度 0~100%**，按个性化遗忘曲线随时间衰减（衰减速率 = 该家具 SRS 间隔的倒数）。
- 光泽 < 40%：家具蒙尘，触发「除尘」按钮（= 该卡已到期复习）。
- 复习交互：**先猜后看** —— 点家具 → 屏幕出现"卡背"（问题）→ 用户回忆 → 点击翻开（答案）→ 自评三键「忘了 / 模糊 / 记得」。
- 回答后家具表现：记得=拂尘闪光+升星进度；模糊=半亮；忘了=家具变"旧"，进入**修复任务**（连续 3 天每日见一次，重学模式）。
- **批量养护**：一键进入「大扫除」= 今日复习队列（交错混合），全部完成获得「焕然一新」宝箱。

### 3.3 远征系统（= 新词学习）

- 每条路线=一课：3~5 个新词 + 1 个语法点（尊重工作记忆 7±2 组块）。
- 采集点交互就是**精细加工**：每个词依次出示 图 → 音 → 例句 → 词根（可跳过但不给双倍经验）。
- 路上随机遭遇**旧词回访**（交错练习的引擎级实现）：正确回忆加速前进，忘记则放回队伍末尾。
- 每周日 **Boss 战「祭典语灵」**：综合测验（混合全部模块），胜利得限定家具「祭典纪念品」。

### 3.4 家具工坊（= 生成效应 / 主动产出）

- 每日 1~2 次「造家具」：给出词块/句型 → 用户**自己造一个句子**（或录一段跟读）→ AI 即时轻评（对/语法提示）。
- 产出挂进宫殿：**DIY 家具带签名**，光泽衰减比买来的慢 20%（"自己亲手做的更难忘"的隐喻）。
- 跟读模式：录音 → AI 发音评分 → 分数决定家具精细度（青铜/白银/黄金雕工）。

### 3.5 社交系统（友好向，无竞争压力）

- **串门**：参观好友宫殿、点灯祝福（给对方家具 +5 光泽，每日 3 次上限）。
- **宫殿展览会**：每周主题展（如"我的五十音庭院"），按养护完成度与布置用心度投票，不按考试分数排名。
- **联盟工坊**：与好友合建一座共享建筑，每人养护自己负责的房间（轻协作）。

### 3.6 成就与收集

- 徽章：全收集（五十音全收藏）、连击（连养 7/30/100 天）、建筑师（宫殿等级）、初造者（首个 DIY）。
- 记忆年鉴：专属可视化「我的遗忘曲线 + 薄弱房间」（数据驱动个性化，薄弱房间自动置顶建议修缮）。

### 3.7 经济系统（轻量）

- 货币：**烛火**（复习产出）用于购买墙纸、装饰件——只影响美观，不影响学习。
- 体力：新词远征需要少量体力，每日刷新；预算用尽后提示**休息与睡眠**（呼应记忆节律，而非卡玩家）。

## 四、学习引擎设计

### 4.1 铁律：游戏状态 = 学习状态的投影（Projection）

**游戏化字段绝不写入 SRS 核心数据**。光泽、星等、稀有度只是 `review_log` + 词卡状态的**派生态**，随时可重算、可回滚，杜绝"玩家为了好看而谎报记忆"污染算法。

```
review_log（唯一事实来源）
   │ 派生 / 投影（可缓存在本地，可失效）
   ▼
游戏状态：光泽值 · 家具星级 · 蒙尘标记 · 图鉴点亮 · 宫殿等级
```

### 4.2 光泽衰减模型

- 每张卡有自己的 SRS 间隔 I（天）与下一复习时刻。
- 光泽 = `max(0, 100 - 衰减率 × 距上次复习天数)`，其中衰减率与该卡的 EF/历史成功率挂钩（记得多=衰减慢）。
- 蒙尘阈值（40%）≈ 逾期复习信号；答对后光泽回满并提高"防尘"等级（间隔拉长）。
- 视觉 + 数值双重反馈：光泽变化通过 粒子特效（除尘闪光）、 环境变化（宫殿亮度）表达 —— **让遗忘曲线可以被"看见"**。

### 4.3 复习模式双入口

| 模式 | 触发 | 交互 | 对应方法 |
| --- | --- | --- | --- |
| 除尘（侧车） | 零散时间点击宫殿里的蒙尘家具 | 单卡先猜后看 + 三键自评 | 主动回忆 · 间隔重复 |
| 大扫除（专注队列） | 番茄钟式 15~25 分钟会话 | 交错混合队列连刷，结束即得宝箱 | 主动回忆 · 交错练习 · 专注 |

### 4.4 遗忘与修复

- 连续答错 2 次的家具进入「修复清单」：接下来 3 天每日优先出现（relearning 状态，间隔 1 天）。
- 修复完成家具获得「重铸」特效，并在年鉴里留下记录（失败记忆也被温柔对待）。

### 4.5 SRS 引擎选型

沿用调研文档第六章结论：**MVP 用 SM-2，数据积累后切换 FSRS**；三按钮自评直接驱动。

## 五、技术架构

### 5.1 总体分层

```
┌──────────────────────────────────────────────────────┐
│                    客户端 App（离线优先）               │
│  ┌────────────┐ ┌────────────┐ ┌──────────────────┐  │
│  │ 游戏表现层  │ │  学习引擎层 │ │     数据层        │  │
│  │ 宫殿渲染(2D)│ │ SRS引擎     │ │ SQLite 本地库     │  │
│  │ 动效/音效   │ │ 卡片交互    │ │ 复习日志/宫殿快照  │  │
│  │ 状态机      │ │ 跟读评分    │ │ 图鉴/成就/偏好    │  │
│  └────────────┘ └────────────┘ └──────────────────┘  │
│                  ▲ 学习引擎与表现层之间只走「投影接口」   │
└──────────────┬───────────────────────────────────────┘
               │ 同步（REST / WebSocket，合并 + 冲突消解）
┌──────────────▼───────────────────────────────────────┐
│                  服务端                                │
│  网关 → 用户/成就/社交 · 词库 · AI · 同步 · 数据仓库     │
└──────────────────────────────────────────────────────┘
```

### 5.2 客户端架构（Flutter / React Native，2D 渲染）

| 模块 | 职责 | 关键点 |
| --- | --- | --- |
| 宫殿渲染器 | 房间布局、家具摆放、粒子特效 | 锁帧 60fps；家具资源懒加载；离线可用 |
| 游戏状态机 | 远征 / 养护 / 安眠 / 展览会等模式切换 | 与学习引擎解耦，只订阅投影 |
| SRS 引擎 | SM-2 → FSRS；维护 pending 队列 | **本地纯函数**，可单测、可降级 |
| 卡片播放器 | 先猜后看、打字、跟读、听写四类交互 | 一键切换语言引擎（ja/en） |
| 离线同步器 | 日志增量上传、宫殿快照恢复 | 断网可连续学习超过 1 周 |
| 本地存储 | SQLite（复习日志）/ 资源缓存（音频图片） | 词库按需下载（语言包可离线） |

### 5.3 服务端架构

| 服务 | 职责 | 说明 |
| --- | --- | --- |
| API 网关 | 鉴权、限流、路由 | JWT + 设备绑定 |
| 用户服务 | 档案、设置、推送（晨间/睡前） | 推送场景 = 记忆节律自动化 |
| 词库服务 | 词条、例句、音频、图鉴元数据 | 双语种 CDN 分发 |
| AI 服务 | 造句纠错、发音评分、i+1 生词过滤、内容生成 | LLM + 传统 TTS/ASR 组合 |
| 同步服务 | 复习日志合流（版本化/CRDT） | 多设备不丢数据 |
| 数据仓库 | 复习日志分析、遗忘曲线聚合成报表 | 只读消费，不反向写游戏状态 |

### 5.4 数据模型（在调研文档第七章基础上扩展）

- `words` / `cards` / `review_log` / `users` / `user_settings`：字段与文档一致。
- 新增游戏域（**独立于学习域**，仅用于表现与激励）：

```json
{
  "furniture": {
    "card_id": "ja-000123",
    "room": "客厅",
    "position": {"x": 4.2, "y": 3.1, "rot": 0.5},
    "material": "wood|bell|page",
    "rarity": "R|SR|SSR",
    "crafted": true,
    "shine": 82,          // 光泽投影，可随时由 review_log 重算
    "star": 2
  },
  "palace": {
    "rooms_unlocked": ["庭院", "客厅"],
    "level": 4,
    "theme": "sakura"
  }
}
```

- **写入路径**：复习动作 → `review_log` → 投影计算 → 更新 `furniture.shine`。游戏动作（摆放/装修）只改 `furniture` 本身。

### 5.5 AI 能力清单

| 能力 | 用途 | 对应玩法 |
| --- | --- | --- |
| TTS | 家具铃音材质、例句朗读 | 多模态 |
| 发音评分（ASR） | 跟读 DIY 雕工评级 | 生成效应 |
| 造句纠错（LLM） | 工坊即时轻评 | 生成效应 |
| 生词过滤（LLM/NLP） | 分级阅读、i+1 内容推送 | 沉浸输入 |
| 内容生成（LLM） | 故事化例句、远征路线趣味文案 | 意义感 |

## 六、数据闭环

```
词库服务 → 远征采集(学新词) → 生成多张卡(SRS) → 家具入宫(投影)
    → 养护/大扫除(复习) → review_log → SRS 更新间隔 & 衰减速率
    → 投影重算(光泽/星级/宫殿等级) → 年鉴报表 → 薄弱房间 → 修复清单
    → 远征路线智能加权(爱忘的多出现) → 循环
```

**一个复习动作 = 一次科学记录 + 一次游戏事件**，二者合流但写在不同表，保证可玩性与可解释性并存。

## 八、设计红线：游戏化不背叛科学

1. **回忆失败永远温和**：忘词=家具蒙尘，不是惩罚（调研文档：焦虑抑制提取）。
2. **游戏激励只加速流程，不替代算法决策**：不能"氪烛火"跳过一次复习后还假装记住了；SRS 排期只由行为数据决定。
3. **每日预算即防沉迷**：体力与复习预算用尽后引导休息/睡眠，拒绝拉停留时长式的设计。
4. **稀有度不嘲讽新手**：SSR 家具靠坚持养护获得，不靠充值——付费只买纯装饰（墙纸）。
5. **安眠模式不打扰**：睡前复习包自动结束，早安提醒在用户设定时间后 1 小时才可重复推送。
