# 「收藏 + 记忆」模式设计：私人记忆博物馆

> 评估一个方向：让用户**先收藏自己想要记住的东西**，App 把它们变成可复习的记忆卡 + 展品。
> 结论先行：**值得做，但它不是"记忆宫殿"的替代品，而是第二支柱**——官方课程馆负责"系统与付费"，私人收藏馆负责"主动与留存"，双轨并行。

## 一、模式解析：收藏 + 记忆是什么

### 1.1 一句话

> **用户收藏"与我有关的东西"（照片、句子、票据、灵感），App 用 AI 把它变成记忆卡，用 SRS 让它忘不掉，用展柜让它被看见。**

### 1.2 与"课程型记忆"的本质区别

| 维度 | 课程型（现在的宫殿） | 收藏型（本设计） |
| --- | --- | --- |
| 内容来源 | 平台词库（JLPT/CEFR） | **用户自己选**（拍照/剪藏） |
| 学习动机 | 外部目标（考试/课程推进） | **内在情感**（这是我的咖啡/我的旅行/我的工作） |
| 记忆编码 | 语义为主（词义+例句） | **情景+情绪**（真实场景+情感附着） |
| 复习对象 | 官方词条 | 与用户生活绑定的个人词条 |
| 复购/付费 | 订阅解锁官方内容 | 订阅解锁"无限收藏 + AI 成卡" |
| 护城河 | 词库与算法 | 用户的藏品 = 迁移成本（他人无法复制） |

### 1.3 与相邻产品的边界

| 产品 | 做法 | 我们的差异化 |
| --- | --- | --- |
| CapWords | 拍照→贴纸词卡，提供场景词 | 它只服务"外语词汇"；我们把收藏扩展到**任意知识与记忆**，且**有 SRS 复习引擎 + 宫殿体系**（它"拍完即学、学了缺复习"） |
| Pocket/剪藏 × Anki | 剪藏→闪卡 | 我们把"收藏"从工具动作升级为**有情绪的收藏家体验**（展柜/系列/时间胶囊） |
| 普通相册 | 照片存储 | 我们不存照片，**存记忆**——照片只是记忆的入口 |

## 二、五种形态对比

| 形态 | 核心动作 | 记忆科学 | 成本 | 风险 | 判断 |
| --- | --- | --- | --- | --- | --- |
| A. 摄影收藏 | 拍下所见事物 → 自动成词卡 | 情景记忆（强） | 中（AI 识别） | 与 CapWords 撞车 | 做，但只做入口 |
| B. 剪藏收藏 | 阅读/刷信息时收藏句子片段 | 精细加工（强） | 低 | 版权敏感 | **做（主力）** |
| C. 系列卡片 | 复习解锁同系列下一张 | 收集驱动（中） | 中 | 需内容生产 | 官方馆已有，收藏馆复用 |
| D. 时间胶囊 | 收藏纪念物，N 天后回顾 | 情景+惊奇（强） | 低 | 依赖用户留存 | 做（形态已在小玩法库） |
| E. 博物馆叙事 | 玩家=馆长，藏品+展柜 | 空间化（强） | 低-中 | 与宫殿重叠 | 作为收藏馆的"皮肤" |

> **结论**：A、B、D、E 组合 = "私人记忆博物馆"；C 留给官方馆。

## 三、推荐主形态：私人记忆博物馆

### 3.1 世界观升级（不推翻宫殿，加一个"馆"）

- 你的记忆宫殿里多了一座**私人博物馆**：玩家从"建筑师"兼任"馆长"。
- 官方馆（课程）：六千词的系统收藏（JLPT 分级、语法工坊）——**付费主体**。
- 私人馆（收藏）：你亲手放进来的"人生藏品"——**主动与留存的来源**。

### 3.2 核心流程

```
收藏入口（三选）：
  ① 拍照：咖啡/路牌/机票 → AI 识别 → 生成卡（图+双语词条+例句）
  ② 剪藏：刷到的句子/段落 → 一键进馆（带原文链接）
  ③ 手录：想记住的人名/概念/清单 → 手动建卡
        ↓
AI 成卡：自动补释义/例句/发音（可编辑，不可用原图 → 生成卡面）
        ↓
入展柜：成为一件"藏品"，按主题自动分组（我的咖啡馆/我的旅程/我的工作）
        ↓
SRS 养护：藏品会蒙尘 → 复习=清洁展柜（伐木复用，零新机制）
        ↓
成长见证：系列集齐发金光；30 天前的藏品自动开"时间胶囊"回顾
        ↓
分享海报：我的博物馆名片 → 好友来参观（轻社交，已有消息墙思路）
```

### 3.3 游戏化叙事（馆长的一天）

| 系统 | 翻译 |
| --- | --- |
| 收藏 | 逛世界"捡宝贝" |
| AI 成卡 | 请鉴定师（AI）把宝贝做成展签 |
| 展柜分组 | 按主题开"馆中馆"（我的东京线/我的咖啡学） |
| SRS 养护 | 每周清扫除尘（复用蜡烛/除尘机制） |
| 系列收集 | 集齐 XX 张点亮馆名（如"咖啡师の馆"） |
| 时间胶囊 | 每月回顾一次"那时候的我" |

## 四、为什么"收藏"本身就让记忆更强

1. **自主感（自我决定理论 SDT）**：学过动机研究的都知道——外部安排的内容产生坚持内耗，自己选的内容自带动力。"我要记住它"比"平台要我记它"的复习完成率高得多，这也是 CapWords 能获奖的隐性原因之一。
2. **情境 + 情绪双重编码**：方法论第二章（精细加工）与第一章（情景记忆）——收藏一定是"我在现场"的记忆，照片里的那杯咖啡 = 视觉 + 场景 + 情绪三通道编码，比配图库强一个量级。
3. **生成效应升级**：原版是"造一个句子"，收藏是"造一个记忆"——用户亲手判定"这值得我记住"，判定行为本身就是深层加工。
4. **仪式感与见证**：展柜让"我的积累"被看见（与时间胶囊同一心理机制）；藏品数量 = 个人记忆资产的可见化。

## 五、六大方法如何落进收藏模式

| 方法 | 收藏模式中的落点 |
| --- | --- |
| 间隔重复 | 藏品蒙尘 → 除尘复习（与原引擎完全同一套，零新增复杂度） |
| 主动回忆 | 复习时先猜"这藏品是什么/这个词怎么读"，再翻展签 |
| 精细加工 | 收藏时强制填"为什么收藏它"（一句话）——AI 据此生成个性化例句 |
| 记忆宫殿 | 展柜 = 空间化；我的东京线 = 一条记忆路线（Method of Loci 天然场景） |
| 交错练习 | 每周大扫除 = 官方词 + 私人藏混合队列 |
| 生成效应 | 为藏品写一句话/录一段音（可选） |

> 注意：私人馆与官方馆共用同一个 SRS 引擎和同一套投影机制（架构不变），**只是内容来源不同**。

## 六、风险与边界（诚实评估）

| 风险 | 评估 | 对策 |
| --- | --- | --- |
| 内容零散、无体系 | 系统性学习者会嫌弃 | 官方馆兜底系统学习；私人馆明确定位"补充与热爱" |
| 冷启动空转（新用户没有藏品） | 高 | 开局"种子引导"：内置 5 个示例藏品（一杯咖啡/一张 CD/一张车票）+ 引导拍第一件 |
| 只收藏不复习（囤积） | **中高（最大风险）** | **复利式设计**：藏品会蒙尘，馆主身份会"松动"，但永不丢失（红线：不惩罚）——用"展柜结灰"的视觉不适替代强迫 |
| AI 识别/成卡质量差 | 中 | 全部可手动编辑；识别失败降级为"手录模板" |
| 剪藏版权 | 低-中 | 只存"引用+链接"，不托管原文 |
| 与 CapWords 同质 | 低 | 维度不同：它做采集（拍完没了复习），我们做**沉淀**（SRS+展柜+胶囊） |
| 收藏变相册（只存不学） | 中 | 展柜内存的只能是"已学会的"（成卡+至少复习 1 次才可展出）——把"学会"变成"展出"的门槛，防止变成照片库 |

### 6.1 「防囤积」机制细节（关键亮点）

```
收藏进入"入库区"，尚未展出：
  - 首次复习通过 → 正式进入展柜（学会的门槛）
  - 超过 3 天未复习 → 藏品开始"结灰"，馆主收到轻提示（非强制）
  - 连续 7 天未处理 → 移入"待清理箱"（视觉上移出主展柜，不删除、不惩罚）
目的：把"囤积"的惰性转化为"维护展柜"的轻任务，而不是强迫复习。
```

## 七、MVP 与验证指标

### 7.1 最小闭环（独立开发者 2~3 周开发量）

```
拍照/图片 → AI 识别成卡（手动编辑兜底）→ SRS 复习 → 展柜呈现 + 时间胶囊预览
```

- 首版只支持"照片收藏"一种入口（剪藏后续加）；
- AI 识别用现有 TTS/LLM 管线（离线词库兜底识别失败的常见词）。

### 7.2 验证指标（先行验证再投入）

| 指标 | 目标 | 说明 |
| --- | --- | --- |
| 收藏 → 复习转化率 | > 40% | 收进来的东西必须回流到复习 |
| 私人馆周留存 | >= 官方馆 80% | 证明"收藏"不是一次性新奇 |
| 单藏品平均复习次数（30 天） | > 3 次 | 是否真的在被记（防囤积） |
| 分享海报点击率 | > 15% | 博物馆名片是否出圈 |

## 八、与现有路线的合并方案

| 版本 | 加入内容 | 验证点 |
| --- | --- | --- |
| V0 首版（现有计划） | 官方馆（日语频道 + 宫殿） | 模型验证（留存/付费率） |
| V1.2 | **私人馆 beta**（照片收藏 + 展柜 + 防囤积） | 收藏→复习转化率 > 40% |
| V1.3 | 剪藏入口 + 时间胶囊 + 博物馆名片 | 周留存抬升 |
| V2 | 系列展馆（官方联名主题收藏）、展柜皮肤 | 付费点（展柜皮肤） |
| V3 | 收藏市场（用户互赠藏品图鉴） | 社交生态 |

> **合并原则**：私人馆永远不加"新引擎"——它只复用 SRS、投影、蜡烛、除尘、时间胶囊五件既有武器，新增的只有"收藏入口 + 展柜 UI"。这是独立开发者能扛住的边界。

---

## 结论

> **"收藏 + 记忆"不是换方向，而是补上产品最缺的一块：让用户和内容建立感情联系。**
> 官方馆靠课程留住"要学的人"，私人馆靠收藏留住"爱学的人"——双轨并行，引擎不变，付费主体不变，只多一根"用户自己的词库"支柱。
> 做它最大的理由：**所有竞品都在教用户背"平台选的词"，还没有人让用户背"自己选的词"。**
