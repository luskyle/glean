# 趣味玩法创意库：宫殿之外的"有趣"

> 配套《记忆宫殿App架构设计》：宫殿系统已经覆盖"收集、布置、成长"，本库补足其余的乐趣来源——依恋、惊奇、紧迫、社交、表达、运气。
> 每一条创意都按四个维度评估：**科学增益**（对记忆是否真的有用）、**乐趣来源**、**实现成本**（独立开发者视角）、**伦理风险**（是否触碰设计红线）。
> 铁律不变：游戏化是"记忆科学的用户体验层"，不是装饰皮。

## 一、"有趣"从哪里来：八种乐趣来源

| 来源 | 它满足什么 | 宫殿已覆盖？ |
| --- | --- | --- |
| 养成的依恋 | Nurture：有一只"因我而活"的东西 | ✅ 宫殿等级（冷） |
| 收集与完成 | Collection：图鉴、套装、百分比 | ✅ 家具收集（中） |
| 挑战与成长 | Challenge：可赢的难、看得见的变强 | ✅ 远征/Boss（部分） |
| 布置与表达 | Self-expression：我的宫殿我做主 | ✅ 布置（部分） |
| 惊奇与发现 | Surprise：盲盒、彩蛋、转折 | ❌ **缺** |
| 紧迫与戏剧化 | Drama：会熄灭的蜡烛、来袭的魔物 | ❌ **缺** |
| 社交与关系 | Relationship：被需要、被看见 | ❌ **缺（轻）** |
| 手感与动效 | Juice：丝滑、弹跳、撒花 | ⚠️ 需强化 |

> 结论：宫殿给了玩家"稳固的基石"（依恋/收集/成长/表达），**缺的是"心跳"——惊奇、紧迫、关系和手感**。下面的创意都朝这四个缺口打。

## 三、创意详设 A-F

### A. 养成的依恋：宫殿居民「忆灵」(P0)

- **设定**：一只住在宫里的智能小精灵（猫娘版/辉夜姬版可选，后续可换主题皮肤）。你的宫殿是它的家，**复习=投喂记忆**，连击=它心情变好，长期不复习它会在门口打盹（不苦情、不惩罚）。
- **为什么有效**：多邻国猫头鹰验证了 mascot 的力量（品牌符号 + 依恋情绪）；"为它每天来一次"的情感绑定比"为自己坚持"动力更强；动效上它是 SRS 队列的入口——点它=开始今日养护。
- **科学增益**：复习频率直接可视化（记忆滋养度 = 连击 + 完成率），且不影响 SRS 数据（仍是投影）。
- **伦理**：它永远不"死"，最多"打盹/掉毛"，不制造负罪感。
- **成本**：一只吉祥物动画（程序化形变）+ 心情状态机，独立可做；同时它会成为品牌 IP（营销抓手）。

### B. 惊奇与见证：时间胶囊 (P0)

- **玩法**：每次"记得"的卡有机会被存入胶囊：记录**当时你的选择 + 一句现场语音/输入（可选）+ 日期**。30 天后解锁打开："30 天前你把这词记错了，今天你 5 秒就答对"。
- **第二形态**（岁月相册）：把首次学习到现在的错题墙做成"成长相册"，里程碑（第 100/1000 词）自动生成复盘页。
- **为什么有效**：人类吃"成长见证"这一套（对比过去自己）；把抽象"记忆曲线"变成有温度的具体时刻；打开胶囊的惊喜契合"惊奇"缺口。
- **科学增益**：重温既是检索练习，又强化元认知（看到自己进步 → 继续坚持）。
- **成本**：本地存储几行文本+日期，几乎零成本——**性价比全库最高**。

### C. 紧迫与戏剧化：倒计时蜡烛 (P0) + 遗忘魔物 (P1)

- **蜡烛**：处于"模糊"状态的卡变成宫里的**将熄蜡烛**，24 小时内点亮=复习成功（火焰腾起、铭牌发光）；不点也不惩罚——熄灭后第二天重新点燃即可。
- **为什么有效**：把"该复习了"从通知变成**视觉上正在发生的紧迫**（隐性倒计时），比任何推送都强；同时尊重"模糊→折半"的 SRS 逻辑（蜡烛 = 间隔临界的投影）。
- **魔物夜袭（故事化 Boss）**：每周日 Boss"遗忘语灵"登场，用本周混排真题挑战（已有祭典玩法）——赋予挑战以剧情。若答错率高的词"攻破"房间，进入修复清单（已有机制故事化）。
- **伦理**：蜡烛熄灭无损失、魔物攻破不扣进度——戏剧化只加情绪不加惩罚（红线 1 不破）。

### D. 惊奇与收藏：词拟人卡 + 记忆盲盒 (P1)

- **词拟人卡**：LLM 给高频词造"一句话人设"（如 頑張る = "永远在最后十米冲刺的体育生"），做成**稀有卡面**，复习时出现——一枚彩蛋 = 惊奇 + 联结编码（精细加工）。
- **记忆盲盒（严格限额）**：每日完成养护后送 1 抽，出"限定装饰/拟人卡面/节日彩蛋"，**只影响外观、绝不影响学习进度与 SRS**；不出无限抽（防赌博化）。
- **伦理**：盲盒不给学习加速、不卖体力——装饰自由，红线 5 之内。

### E. 社交与关系（轻量，不重服务器）(P1)

- **记忆交换所**：与好友**等价交换一张家具**（我用"覚える"换你的"remember"）。科学彩蛋：讲给别人听记得更牢（教授他人效应）——换卡时强制回放"这是什么样的词"，双方都受益。
- **回忆留言墙**：好友宫殿里留言（"你这座五十音庭院我逛过了"），异步、低成本。
- **双人记忆对决赛**（周更帖）：同一组 20 词的短期记忆赛，只比"养护完成度 + 正确率"，不比绝对水平——维持友好竞争（沿用展览会原则）。

### F. 每日新意：minigame 轮换 + 昼夜季节 (P0/P1)

- **每日 minigame（三选一轮换，都是一屏）**：
  1. **三词成句**：用今日 3 个词拼一句有意思的话（生成效应，LLM 轻评）；
  2. **听音寻物**：放一段音频，在宫殿场景里点出对应的家具（听力提取）；
  3. **拆字成谜**：汉字部件打散重组（日语双编码特化）。
- 轮换机制保证"每天都有点不一样"，三个各 ~1 屏的开发量远小于一个重度玩法。
- **昼夜/季节**：宫殿随真实时间变化（晨光/烛火/星空），节气与节日有氛围特效——几乎零成本（时间变量 + 色调叠加），却让每次打开都"活"着。

## 四、筛选与优先级

### 4.1 评估口径

| 维度 | 怎么打分 |
| --- | --- |
| 科学增益 | 是否直接服务记忆科学（SRS/提取/生成/多模态/节律） |
| 乐趣缺口 | 是否命中"惊奇/紧迫/关系/手感"四大缺口 |
| 成本 | 独立开发者单人可承接程度 |
| 风险 | 是否触碰红线（惩罚、赌博、绑架睡眠、破坏 SRS） |

### 4.2 推荐落地的首批组合（P0 六个）

```
① 宫殿居民忆灵      → 依恋入口：点它开始养护
② 倒计时蜡烛        → 紧迫入口：模糊词该抢救了
③ 时间胶囊          → 惊奇入口：30 天后开盲盒式的成长见证
④ 每日 minigame 轮换 → 节奏入口：每一天都有点不一样
⑤ 三词成句          → 产出入口：生成效应已成日常
⑥ 昼夜系统          → 氛围底层：让宫殿"活着"
```

> 这六个全部"挂"在已有系统上（复习队列 / SRS 状态 / 词库 / 时间轴），**没有一个是新服务器、新架构**，独立开发者一个 Sprint（2 周）内可上 2~3 个。

## 五、与核心循环的挂接原则

1. **复用原则**：新玩法优先挂在 SRS 队列、词库、宫殿状态三根柱子上，而不是造第四根柱子（交换所=卡牌路由；蜡烛=状态投影；胶囊=日志回放）。
2. **一动作双收益**：一次复习 → 蜡烛点亮 + 忆灵投喂 + 盲盒进度 + 相册记录——游戏事件与科学记录仍然分离（投影原则不破）。
3. **新鲜感轮换而非堆叠**：每日只突出 1 个新意点（今天有蜡烛待灭 / 今日 minigame 是拆字），避免 22 个玩法同时在屏幕上打架。
4. **情绪只加不减**：戏剧化只增加"可赢的挑战感"，永远不增加"失去感"——熄蜡烛、魔物破门、盲盒空奖都不造成损失。

## 六、设计红线复核

| 红线 | 本库创意是否触碰 |
| --- | --- |
| 回忆失败永远温和 | ✅ 蜡烛熄灭无损失、魔物不扣进度 |
| 游戏激励不替代算法决策 | ✅ 盲盒/皮肤不加速 SRS、不兑换"跳过复习" |
| 每日预算即防沉迷 | ✅ minigame 与复习共用一份预算，不做无限刷 |
| 稀有度不嘲讽新手 | ✅ 拟人卡人人可集，稀有只来自坚持 |
| 不绑架睡眠 | ✅ 昼夜系统只做氛围，不推送"凌晨维护"任务 |

## 七、独立开发者落地节奏

| 阶段 | 加入的玩法 | 节奏 |
| --- | --- | --- |
| MVP（首发） | 宫殿 + 忆灵 + 蜡烛 + 三词成句 | 最小可玩闭环，先验证留存 |
| V1.1（第 2 月） | 时间胶囊 + 昼夜 + minigame 轮换 | 惊奇 × 氛围，拉周留存 |
| V1.2（第 4 月） | 词拟人卡 + 记忆盲盒 + 拆字/听音变体 | 收藏 × 彩蛋，制造讨论度 |
| V2（半年+） | 交换所 + 双人对决赛 + 足迹留言 | 轻社交，拉好友回流 |
| 远期 | 记忆之森（第二场景）、全球共亮星空 | 平台化叙事 |

> **一句话**：宫殿负责"记住后的归属"，本次补上的六大 P0 玩法负责"忘记前的**心跳**"——前者建心态，后者保节奏，合起来才是"好玩又有用"的完整闭环。
